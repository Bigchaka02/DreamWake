## Unreleased

- RETRIES: number of attempts for retried calls (3).
- BASE_URL: server address used by the client.
- TIMEOUT_MS: request timeout for the client, in milliseconds (30000).
- SERVICE_NAME: name of the service used by the client (dreamwake).
- RETRY_BACKOFF_SECONDS: delay between retry attempts, in seconds (2.0).
